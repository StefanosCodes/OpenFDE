# Agent 1 datasets

Agent 1 currently has three starter Promptfoo scenarios defined in
`../evals/promptfooconfig.yaml`: a no-tool response, an account lookup, and a sequential account and
call lookup.

A versioned dataset will be introduced during the evaluation milestone. It will cover routing,
tool arguments, missing and ambiguous accounts, write approval, tenant isolation, tool failures,
and unnecessary calls without claiming those behaviors are implemented today.
